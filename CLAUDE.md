# Project notes for Claude

Procedural universe game (React 19 + Vite + TypeScript, deployed to GitHub Pages). All art is generated by code.
UI text is Brazilian Portuguese.

## Workflow
- Bump `version` in `package.json` on every round of work — the main menu shows `v{version} · {commit} · {build time}` so the
  owner can confirm GitHub Pages updated.
- Merged PRs never receive new commits: after a merge, restart the working branch from `origin/main` and open a **new** PR.
- Check with `npm run lint` (tsc) and `npm run build`.

## Creature generator rules (`src/lib/creature/`)
These were set by the project owner — keep them:
- **Art direction is flat 2D pixel art** made of ellipses, tapered capsules and polygons (`raster.ts`), with hue-shifted
  6-step ramps, ordered dithering and selective outlines. Do **not** turn it into 3D models/meshes.
  Directions are done like a pixel artist would: `pose.ts` (`Sketch`) only decides *where* each 2D piece goes and the
  painting order for a facing.
- **8 facings** for every stage except the cell (the cell is seen from above only). E, SE, S, NE, N are drawn; W, SW, NW
  are mirrors. Sprites are meant to be placed on the gameplay map.
- **Colour modes**: *Earth-like* (natural pigments) vs *Alien-like* (free, vivid hues). In Earth-like mode fur, skin and
  feathers vary **between species by climate**: pale/white coats in the cold, sand/ochre in deserts, dark/rufous/golden
  in wet tropics, browns/greys in temperate zones. Only tropical birds, poison frogs and reef fish get loud colours.
- **Diet shapes the face** (continuous `genome.fierce`): carnivores look menacing (heavy slanted brow, narrow slit eyes,
  fangs, bared gums, snarl), herbivores calm and gentle (round skull, big glossy eyes with two catch-lights, short soft
  muzzle, slight smile), omnivores are the plain middle ground.
- **Lineage**: cell → larva → aquatic → amphibian → land → 8 civilisation eras, with a **giant branch**
  (aquatic giant → amphibian giant → land giant). Colours, pattern and eyes carry through the stages.
- **Civilisations keep the species' anatomy**; only clothes and small personal objects change per era. Clothes are
  **civilian** — no armour, weapons, uniforms or work/profession gear (no knights, soldiers or astronauts). Each era has
  several options per slot and a citizen index picks the combination.
- **No equipment at all** for civilisations: hands stay free - no tools, weapons, bags, baskets, canes or held objects.
  Only civilian clothes, hats, shoes and jewellery.
- Animations: idle, walk, run, fly (fliers; landed = wings folded), swim. Fliers take off, fly and land in-game; swimmers
  surface for ~5 s (random) and dive again with splashes/ripples tinted by the planet's own water colour.
- Living planets carry **200+ species** (`src/lib/fauna/species.ts`), animal stages only (no civilisations yet), spawned
  per chunk by biome/water. Landing with the character opens the creature screen; the player plays their species'
  tribal era.
- Everything is a deterministic function of `(seed, params, mode)`; random numbers are drawn up-front in a fixed order so
  sliders morph the same species instead of reshuffling it.

## Demo reel (`src/components/Demo/`)
- Menu → "Assistir demo": a self-running film of the living worlds, no editors and no HUD - only the engine FPS
  (`frameMeter`: 1000 / CPU ms per frame, i.e. uncapped by the monitor). Esc or the auto-hiding X leaves it.
- `DemoReel` plays space shots (gas-giant flyby, planet approach + dive) and mounts `SurvivalView` with a `cinematic`
  director (`director.ts`): shots are specs (coast / wild / peaks / cold / rise, hours, weather, zoom); spots are scouted
  on the planet map and refined on the loaded tiles. Add worlds or shots in the `PLANETS` list. `#demo=N` starts at world N.
